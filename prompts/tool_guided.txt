Use the Python tool only when it materially helps.

Good uses:
- checking small cases
- testing a conjectured pattern
- evaluating a closed form
- verifying arithmetic, modular reduction, or brute-force bounds on a reduced search space

Avoid using Python as a substitute for all reasoning.
Before using the tool, say what you are checking.
After using the tool, explain how the result supports the mathematical argument.
If the problem involves huge exponents or recurrences, prefer exploring smaller cases first and then generalizing.
